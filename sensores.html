¿Cómo recuperar lecturas faltantes y medir la distorsión que producen datos con ruido?

Se parte de una señal sintética conocida y(t) y se interpolan los valores en puntos donde no hay medición.

01   Del problema al modelo

Con nodos de medición y sus valores, se reconstruye la señal con Lagrange, Newton (diferencias divididas) y splines cúbicos. Se ocultan algunos puntos para medir el error real de predicción.

Lagrange: P(x) = Σ yᵢ·Lᵢ(x) Newton: P(x) = f[x₀] + f[x₀,x₁](x−x₀) + …
Spline: Sᵢ(x) = aᵢ + bᵢ(x−xᵢ) + cᵢ(x−xᵢ)² + dᵢ(x−xᵢ)³ Raíz: interp(x) − umbral = 0
¿Qué nos dicen los errores?
El error sobre puntos ocultados mide cuán bien predice el interpolador datos que no vio. Nodos desfavorables pueden generar el fenómeno de Runge y una reconstrucción poco confiable.
