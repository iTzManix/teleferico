Error de cada método
Se usa error relativo para comparar magnitudes diferentes. Ceros se dibujan en 10⁻¹⁶ y errores mayores que 10⁴ en el límite superior; la tabla conserva los valores completos. Una barra de Jacobi fuera del rango no se interpreta como precisión.

Guardar, cerrar y recuperar
Historial local persistente de este navegador con las siete entidades del DER propuesto. Guarda un experimento, cierra o recarga la página y recupera su resultado original. “Repetir” recalcula las entradas y compara con el snapshot. Supabase sigue disponible en los módulos; su prueba autenticada es un control separado.
