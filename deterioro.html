¿Cuándo alcanzaría un rodamiento un nivel de deterioro que sugiera una inspección?

Imaginemos un indicador sintético que resume su estado. No medimos el desgaste real: construimos una trayectoria hipotética para estudiar cómo las observaciones, el sesgo y los métodos afectan nuestra estimación.

01   Del problema al modelo

Representamos el índice con una curva cuadrática. La lectura observada incluye un sesgo constante del sensor:

D(t) = D₀ + αt + βt² y(t) = D(t) + s

El sesgo s se obtiene mediante una calibración independiente. Sin ella, las lecturas solo permiten observar la suma D₀ + s: no es posible distinguir ambos valores de forma única.

Con lecturas en los meses 0, 1 y 2 y una medida independiente del sesgo, construimos cuatro ecuaciones. Sus ecuaciones normales forman un sistema simétrico definido positivo. Comparamos Jacobi, Gauss-Seidel, LU y gradiente conjugado con la solución de referencia de las cuatro observaciones.

¿Qué nos dicen los errores?
El residuo mide cuánto incumple la solución el sistema. El error frente a la referencia mide la diferencia entre soluciones. Un residuo pequeño no siempre implica un error pequeño si el problema está mal condicionado.

      UNA LECTURA RESPONSABLE / 04

      El resultado no es
      el final de la pregunta.

      Conclusión numérica

      Compara residuos, errores y convergencia. El mal condicionamiento puede hacer que cambios pequeños en los datos alteren mucho los parámetros; la falta de convergencia de un algoritmo es un fenómeno distinto.

      Conclusión del problema

      La curva estima cuándo se alcanza un umbral elegido bajo los supuestos del modelo. Es una señal educativa para planificar una inspección, no una predicción de falla ni una recomendación operativa.
