¿Cuánto tiempo y distancia necesita una cabina para detenerse?

El modelo considera una velocidad inicial v₀, un tiempo de reacción tᵣ con velocidad constante y un frenado con desaceleración a.

01   Del problema al modelo

Tras la reacción, se resuelve el sistema de EDO x′ = v y v′ = −a. La solución analítica de referencia es:

t_total = tᵣ + v₀/a d_total = v₀·tᵣ + v₀²/(2a)

Se integran las ecuaciones con RK2 y RK4, se calcula la distancia con trapecio, Simpson y Romberg, y se busca el instante v(t) = 0 con bisección, Newton y secante.

¿Qué nos dicen los errores?
El error absoluto y relativo miden la diferencia frente a la referencia analítica. La sensibilidad muestra cómo cambios en la desaceleración afectan el tiempo de detención.
